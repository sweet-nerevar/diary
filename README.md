## Версия 0.4 — заполнен раздел «Хроники»

Все 11 глав раздела «Хроники» теперь содержат проверенные по рекапу тексты, интро и источники (страницы). Заменены только `data.js`, `app.js`, `style.css`; разделы «Личные записи», «Люди», «Расследования», «Архив» по-прежнему имеют заглушки. Полный текст доступен отдельным файлом `Хроники_тексты.md`.

**Для существующего Codespace:** замените в проекте эти три файла из архива, либо загрузите весь проект в отдельную папку. Существующий сундук `room-chest` не меняется. Тексты — третье лицо, не «я» от лица Мэгги.

# Хроники Мэгги — PAPER EDITION v0.4

Светлый интерактивный мета-дневник: бумажная сетка, типографика под старинную печать, дизайнерская адаптация пиксельного дизеринга. Это **новый самостоятельный проект**, он не изменяет `room-chest`.

## Открыть

- `diary.html` — сразу интерфейс дневника.
- `index.html` — маленькая CSS-книжечка для встраивания в tldraw. При нажатии интерфейс раскрывается на весь экран через Fullscreen API, если хост разрешает fullscreen; иначе появляется ссылка открыть дневник в новой вкладке.
- Открытие внутри GitHub Pages: положить содержимое папки в отдельный репозиторий или подкаталог Pages и использовать `index.html` как iframe. **Не заменять файлы сундука**.
- Для собственной иллюстрации книжечки: положить `book.png` рядом с `index.html`; CSS-книжечка автоматически сменится картинкой.

## Дизайн и навигация

- **Главная** (`#home/start`) — три колонки, левый и правый блоки прокручиваются независимо, большая центральная иллюстрация остается неподвижной.
- **Каталог** (`#chronicle`, `#diary`, `#people`, `#mysteries`, `#archive`) — слева описание и оглавление, справа сетка глав с заменяемыми превью.
- **Глава** (`#chronicle/ball`) — центральный текст с разделами, слева список глав, справа оглавление текущей страницы.
- **Поиск:** кнопка в шапке или `Ctrl+K` / `Cmd+K`; `Esc` закрывает, `Enter` открывает первый результат.
- На телефонах колонки складываются вертикально, внутри раздела остается горизонтальная навигация.

## Где менять информацию

Вся структура живет в `data.js` (`window.MAGGIE_DIARY.sections`). Можно менять имена, описания, порядок и текст блоков — навигация и поиск обновятся автоматически. **Раздел «Хроники» заполнен по рекапу Литы, остальные разделы по-прежнему содержат заглушки.**

Пример главы (одной из страниц в `sections`):

```js
{
  id: 'ball',
  title: 'День бала',
  lead: 'Бал, который начался с танцев и закончился допросом.',
  status: 'ПО РЕКАПУ',
  blocks: [
    { id: 'events', heading: 'События', text: 'Здесь будет текст главы...' },
    { id: 'interview', heading: 'Разговор с Эдитой', text: '...' }
  ]
}
```

## Изображения

В `data.js` сверху есть объект `art`:

```js
art: {
  titleImage: 'assets/my-cover.png',
  sectionImages: { chronicle: 'assets/my-chronicles.png' },
  pageImages: {
    'chronicle/ball': {
      card: 'assets/ball-card.png',  // карточка в каталоге
      cover: 'assets/ball-cover.png', // большая обложка записи
      wide: 'assets/ball-wide.png'   // вставка в тексте
    }
  }
}
```

Если строки пустые, показываются 37 **оригинальных временных монохромных дизеринг-иллюстраций** из папки `assets/`; у каждой главы своя заглушка. Никаких изображений MEK.gallery в проекте нет. Скрипт `make_art.py` нужен только для пересоздания временных иллюстраций; для работы сайта Python не требуется.

## Примечания

- Можно использовать даже офлайн: внешние библиотеки, веб-шрифты, CDN и сервер не нужны.
- Шрифты используются только из установленных системных, с запасными вариантами. Готическая выразительность на разных компьютерах будет слегка различаться. На будущем графическом этапе можно выбрать и подключить подходящий лицензированный веб-шрифт.
- Переписка и рекап Литы **не входят в сайт автоматически**. Факты следует переносить отдельно, различая знания Мэгги и мета-знания игрока.
